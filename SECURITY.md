# Security policy

Please do not report security issues in public issues, discussions or pull requests.

Report privately through GitHub: **Security** tab → **Report a vulnerability**
(https://github.com/launchcal/launchcal.github.io/security/advisories/new).

Include what is affected, how to reproduce it and the impact. You will get a reply as soon as
possible; this is a one-person project, so please allow a few days.

Only the latest version on `main` is supported.
